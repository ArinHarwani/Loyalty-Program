1. 🏗️ System Architecture Overview

LoyaltyQR is a full-stack web application that connects merchants, their customers, and WhatsApp together. Here's how the pieces fit:

Flow Summary

  1. Merchant logs into the web app → creates a campaign → enters a bill amount → generates a QR code
  2. Customer scans QR → enters WhatsApp number → confirms on WhatsApp
  3. Backend records the transaction → calculates progress → sends WhatsApp message via Meta API
  4. Admin (you) manages everything from the admin dashboard — activate/block merchants, view analytics, reset passwords

7. 🔄 Merchant Lifecycle Management

Merchant Status Flow

Signup → inactive (pending your approval) → You activate → active → Subscription expires → inactive again

At any point you can block a merchant (status becomes blocked) and later unblock them.

activeFull access to dashboard, campaigns, transactions. Customers can scan QR codes.

8. ✅ How to Activate a New Merchant

When a merchant signs up and completes onboarding, they appear in your admin dashboard with status "inactive".

1Go to Admin Dashboard → click on the merchant

Find them in the merchant list and click their row to open their detail page.

2Click "Activate / Renew" button

This opens the Activation Modal.

3Fill in the activation form

• Plan: Select Growth / Business / Pro / Custom
• Duration: 1 / 2 / 3 / 6 months
• Custom Price: (Optional) Override the calculated price
• Custom Customer Limit: (Optional) Override plan default
• Payment Method: UPI / Cash / Bank Transfer / Other
• UTR Number: (Optional) Transaction reference
• Notes: (Optional) Any internal notes
• Start Date: Auto-calculated (today, or day after current subscription ends)
• End Date Override: (Optional) Manually set an end date instead of auto-calculating

4Click "Activate"

The system will set the merchant's status to "active", assign their customer limit, set the subscription dates, and log the payment in subscription history.

💡 Quota Exhaustion Mid-Month

If a merchant exhausts their customer quota in the middle of the month and wants more customers, they need to pay for a new plan. Use the activation modal again — the start date will auto-set to the day after their current subscription ends. Set the End Date Override to match their original end date if you want both plans to expire together.

9. 🔑 How to Reset a Merchant's Password

If a merchant forgets their password and contacts you:

1Go to Admin Dashboard → click on the merchant
2Click "🔑 Reset Password" button

This is in the top-right area of the merchant header, next to the Email button.

3Enter a new password (minimum 6 characters)

Type a new password for them. This is a plain-text field so you can see what you're typing.

4Click "Reset Password"

The password is changed immediately. The merchant is NOT notified by email — you need to tell them the new password yourself (via WhatsApp/call).

10. 🚫 How to Block / Unblock a Merchant

Blocking

On the merchant detail page, scroll to Subscription Management section and click "Block Merchant". This immediately:

  • Sets their status to "blocked"
  • They see a "Account Suspended" page when they try to log in
  • Their WhatsApp messages (birthday, expiry warnings) stop being sent
  • Customers can no longer scan QR codes

Unblocking

Click "Unblock Merchant" on the same page. This restores their status to the previous state (usually "inactive" — you may need to activate them again).

11. 💬 WhatsApp Integration — Templates & Costs

Approved Meta Templates

Template NameCategoryVariablesCostWhen Sent
birthday Marketing {{1}} = customer name
{{2}} = shop name (appears twice)		 ₹0.8631 Daily at 9 AM IST on customer birthdays
account_update Utility {{1}} = shop name
Button: "Check Status"		 ₹0.115 3 days before enrollment deadline

Regular Text Messages (Not Templates)

These are sent as free-form text within the 24-hour conversation window (service messages, ₹0.00 cost):

  • Welcome message — when customer first joins
  • Progress update — after every transaction
  • Completion + claim code — when goal is reached
  • Status check reply — when customer replies with "STATUS" or similar keyword

⚠️ Important: 24-Hour Window Rule

WhatsApp allows free-form text messages only within 24 hours of the customer's last interaction. This is why our system sends progress updates immediately after a scan (within the window). The birthday and expiry templates work outside this window because they are Meta-approved templates.

12. ⏰ Automated Cron Jobs

These run automatically on Vercel's cron scheduler. You don't need to do anything — they run by themselves.

Cron JobScheduleWhat It Does
/api/cron/expire Daily at 1:00 AM IST (19:30 UTC) 1. Marks past-deadline enrollments as "expired"
2. Sends 3-day warning via account_update template to customers nearing deadline
/api/cron/birthday Daily at 9:00 AM IST (3:30 UTC) Finds customers whose birthday is today and sends the birthday template from each active merchant they're enrolled with
/api/cron/cleanup Manual (not scheduled) Deletes expired QR tokens older than 7 days and message logs older than 6 months. Run manually when needed.

💡 How to manually run a cron job

Open your browser and visit the URL with the auth header. Or use this curl command:
curl -H "Authorization: Bearer YOUR_CRON_SECRET" https://yourdomain.com/api/cron/cleanup

13. 👥 Customer Quota & Upgrades

How Quota Works

  • Each plan has a customer limit (Growth = 1000, Business = 2000, Pro = 5000)
  • The count is based on unique customers (distinct WhatsApp numbers enrolled with that merchant)
  • At 80% usage, the merchant sees a yellow warning banner on their dashboard
  • At 100%, new customer scans will fail with an error

When a Merchant Requests More Quota

1They contact you (WhatsApp/phone)

"My customer limit is full, I want to add more customers."

2You decide the pricing

They pay the full plan price again (e.g., ₹999 for another 1000 customers on Growth). This is NOT a top-up — it's a new subscription block.

3Open their merchant detail page → click "Activate / Renew"

Select their plan, set the amount they paid. Important: Set the End Date Override to their existing subscription end date so both plan periods align.

14. 🗑️ How to Delete a Merchant

⚠️ Pre-requisite: Run the Cascade Delete Migration

Before you can delete a merchant from the Supabase Table Editor, you need to have run the migration-v6-cascade-delete.sql migration. This changes the foreign keys so that deleting a merchant automatically deletes all their related data (enrollments, transactions, QR tokens, message logs).

1Go to Supabase Dashboard → SQL Editor

If you haven't already, paste and run the contents of supabase/migration-v6-cascade-delete.sql.

2Go to Supabase → Table Editor → merchants

Find the merchant row, click the checkbox, and click Delete.

3Also delete their Auth user

Go to Supabase → Authentication → Users → find their email → click the three dots → Delete User.

15. 🟢 Supabase Admin Tasks

Accessing the Dashboard

Go to supabase.com/dashboard and log in with your account.

Common SQL Queries

View all active merchants

SELECT id, shop_name, email, subscription_plan, subscription_end_date, customer_limit
FROM merchants
WHERE subscription_status = 'active'
ORDER BY created_at DESC;

Check a merchant's total customers

SELECT COUNT(DISTINCT customer_id) as total_customers
FROM enrollments
WHERE merchant_id = 'PASTE-MERCHANT-ID-HERE';

Delete old QR tokens manually

DELETE FROM qr_tokens
WHERE created_at < NOW() - INTERVAL '7 days';

Delete old message logs manually

DELETE FROM message_logs
WHERE created_at < NOW() - INTERVAL '6 months';

View WhatsApp costs for a merchant this month

SELECT template_name, category, COUNT(*) as count, SUM(cost) as total_cost
FROM message_logs
WHERE merchant_id = 'PASTE-MERCHANT-ID-HERE'
  AND sent_at >= DATE_TRUNC('month', NOW())
GROUP BY template_name, category;

16. ▲ Vercel Deployment

How Deployment Works

Every time you push code to the main branch on GitHub, Vercel automatically builds and deploys the new version. No manual action needed.

Checking Deployment Status

  1. Go to vercel.com/dashboard
  2. Click on the LoyaltyQR project
  3. Check the latest deployment — green checkmark means success, red means failed
  4. Click on a deployment to see build logs

Updating Environment Variables

  1. Go to Vercel Dashboard → Your Project → Settings → Environment Variables
  2. Edit the variable value
  3. Click Save
  4. Important: You must Redeploy for changes to take effect. Go to Deployments → click the three dots on the latest deployment → Redeploy.

18. 🔧 Troubleshooting Guide

❌ "WhatsApp messages are not being sent"

  • Check if WHATSAPP_TOKEN has expired (Meta tokens expire). Regenerate in Meta Business Suite and update in Vercel env vars. Redeploy.
  • Check if Meta WhatsApp credit balance is zero. Top up.
  • Check Vercel function logs for error messages.

❌ "Customer says QR code shows error"

  • QR codes expire after 3 minutes. Generate a new one.
  • Check if the merchant's subscription is active.
  • Check if the merchant has hit their customer limit.

❌ "Vercel deployment is failing"

  • Check the build logs on Vercel dashboard for the specific error.
  • Common issue: TypeScript errors. Run npm run build locally to see the error.
  • Common issue: Corrupted package-lock.json. Run npm install --package-lock-only and push.

❌ "Merchant can't log in"

  • Check if their account exists in Supabase → Authentication → Users.
  • Reset their password from the admin merchant detail page (🔑 button).
  • Check if they are "blocked" — unblock them if needed.

❌ "Birthday messages not sending"

  • Verify the cron job is running in Vercel (check Vercel Dashboard → Crons).
  • Verify the CRON_SECRET env var matches.
  • Check if the customer has birth_month and birth_day set in the database.
  • Check if the merchant is "active" — birthdays only send for active merchants.

❌ "Can't delete a merchant row in Supabase"

  • Run the cascade delete migration: supabase/migration-v6-cascade-delete.sql.
  • This adds ON DELETE CASCADE so deleting a merchant automatically cleans up related data.
